## 👋 About Me

I bridge the gap between development and quality assurance. As a QA Management Lead and Automation Engineer, I focus on building scalable end-to-end automation frameworks, optimizing project workflows, and defining quality metrics to ensure reliable software delivery.

- 🏗️ **Architecture:** Page Object Model (POM), Data-Driven Testing (DDT), and BDD (Cucumber/esbuild)
- 🚀 **Automation Focus:** E2E Web Automation (Playwright, Cypress), Mobile Testing (Appium), and Scripting
- 📊 **QA Management:** Jira workflow orchestration, risk/issue tracking, and Project Health Dashboards
- 🤖 **AI Integration:** Leveraging AI tools (Claude Code CLI, Prompt Engineering) for automated test generation and workflow efficiency
